# Item-manager fixtures

Each fixture's `campaign/` folder is the complete agent-readable synthetic campaign. The sibling `key.yaml` is the answer key and must never be copied into the tested campaign. `create` seeds competing item names, a name shared by a place and character, an existing alias, and scenic-only tableware; `check` seeds a missing brief, contradictory brief/full descriptions, a public secret, omitted item candidate, plot/sheet conflict, scenic lantern, and a recorded exclusion.
